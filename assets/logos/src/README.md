# Logo sources

Nothing in this folder is served. The site uses the derived files one level
up, in `assets/logos/`. These are kept only so a variant can be regenerated
without hunting for the original again.

## Where the served files actually come from

Every mark on the site comes from the organisation's own site, not from a
stock-image aggregator. See `AGENTS.md` for why that rule exists.

| Served file | Origin |
|---|---|
| `cmu.png`, `cmu-light.png` | Official stacked wordmark, inline SVG lifted from cmu.edu, rendered white and `#1f2328` |
| `upmc.png` | UPMC official primary **reversed white** SVG, published by UPMC for dark backgrounds |
| `upmc-light.png` | UPMC official colour SVG |
| `pitt.png` | Shield cropped from the official white lockup on pitt.edu |
| `pitt-light.png` | Derived from `pitt-shield-colour.png` here |
| `strand.png` | Current logo from strandls.com |
| `strand-light.png` | Derived from `strand-supplied.png` here, tagline cropped so the mark keeps its shape across themes |
| `iith.png` | Official horizontal logo from iith.ac.in, cropped to the emblem |
| `algoleap.png` | Current logo from algoleap.com |

## Not kept

The originally supplied IIT Hyderabad file was a JPEG from cleanpng carrying a
tiled watermark across the emblem and a fake transparency checkerboard baked
into the pixels. It was unusable and is not stored here. The official
transparent logo from iith.ac.in replaced it.
